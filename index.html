02 / Primer arranque

Cómo instalar

Windows

  1. Descarga y extrae el ZIP completo.
  2. Abre Instalar.cmd en la carpeta extraída.
  3. Busca GULF SKY 91 en el menú Inicio o abre el lanzador de la carpeta.

Linux

  1. Descarga y extrae el TAR.GZ.
  2. En la carpeta extraída, abre una terminal y ejecuta sh instalar.sh.
  3. Busca GULF SKY '91 en el menú de aplicaciones. También puedes abrir el HTML directamente. BSD: requiere xdg-open para instalar el acceso directo.

macOS

  1. Extrae el ZIP y copia la app a Aplicaciones.
  2. Abre la app; si el sistema la bloquea, abre GulfSky91.html directamente.

ChromeOS, Android e iOS

  1. Descarga el HTML y ábrelo en un navegador compatible.
  2. Si el visor de archivos no ejecuta JavaScript, usa una copia alojada como web estática. En móviles, gira la pantalla y prueba los controles táctiles.

Los paquetes no necesitan permisos de administrador. Los lanzadores abren la edición web en tu navegador predeterminado; no incluyen un motor nativo compilado.

03 / Información técnica

Compatibilidad y rendimiento

¿Qué necesito para jugar?

Un navegador moderno y una GPU compatible con WebGL para el renderizado acelerado. El juego incluye un modo de compatibilidad básico. Los requisitos de FPS y hardware todavía no están validados en equipos reales.

¿Cómo elijo la calidad gráfica?

En el juego, abre Configuración → Gráficos → Test de rendimiento. Elige tu objetivo de FPS y deja que el benchmark recomiende un nivel.

¿Necesito Internet?

El HTML se abre localmente; el multijugador experimental necesita Internet y depende de servicios externos. No se ha validado su funcionamiento entre equipos reales.

¿Cómo desinstalo el juego?

Windows: ejecuta Desinstalar.cmd desde la carpeta instalada en %LOCALAPPDATA%\GulfSky91. Linux/BSD: ejecuta sh ~/.local/share/GulfSky91/desinstalar.sh (o desde XDG_DATA_HOME). macOS: elimina la app. El navegador puede conservar las preferencias guardadas.

¿Por qué no hay un instalador nativo?

La edición Godot todavía no se ha compilado ni probado. El paquete actual instala el HTML local con un lanzador y acceso directo. No se presenta como un juego nativo.
